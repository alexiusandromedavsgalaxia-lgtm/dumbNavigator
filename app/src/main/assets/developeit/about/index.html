dumbNavigator · 0.6

tu navegador dentro de dumb://

dumbNavigator utiliza DumbEngine, un motor nativo basado en Android Canvas que analiza HTML y CSS, calcula el layout y dibuja la página directamente, sin WebView, Chromium ni GeckoView.

DumbEngine nativoHTML/CSS → Canvasdumb:// namespaceoffline-firstlocal publishinglocal bookmarkslocal history

El objetivo es que crear una web interna sea tan sencillo como escribir un dominio y pulsar publicar, sin DNS público ni alojamiento externo.
