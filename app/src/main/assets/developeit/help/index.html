ayuda

Todo lo que ocurre aquí sucede dentro del universo local de dumbNavigator.

direcciones

Escribe uuu.miweb.com y dumbNavigator lo convierte en dumb://uuu.miweb.com/. Si escribes miweb.com, se añade automáticamente uuu..

uuu y jit son prefijos, no dominios. www sí puede formar parte de un dominio interno.

crear webs

  1. abre Crear una web
  2. escribe el dominio interno
  3. pega HTML, CSS y JavaScript
  4. pulsa publicar

La publicación se guarda en el almacenamiento privado de la app y no necesita servidor, DNS ni pago.

navegación

  • atrás y adelante mantienen historial interno
  • ☆ guarda marcadores localmente
  • el menú permite abrir historial, copiar direcciones y recargar
  • los recursos HTTP/HTTPS externos se bloquean

reservas

Los nombres correspondientes a empresas importantes se reservan para evitar confundir una web interna con una web real.
